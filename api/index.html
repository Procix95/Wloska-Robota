API Włoska Robota

Publiczne dane pizzerii z Głupoń koło Kuślina w formacie JSON. Tylko odczyt, bez klucza i bez logowania, można używać z dowolnej strony lub aplikacji (nagłówek CORS jest ustawiony).

Teraz: sprawdzam…

1. Pliki JSON (stan bazowy)

GET https://wloskarobota.eu/api/menu.json

Menu: kategorie, pozycje (nazwa, cena liczbowa i tekstowa, opis, kategoria, plakietki).

GET https://wloskarobota.eu/api/info.json

Adres, telefon, e-mail, linki, miejscowości z dowozem i domyślne godziny otwarcia.

curl https://wloskarobota.eu/api/menu.json
curl https://wloskarobota.eu/api/info.json

Te pliki pokazują stan ze strony, czyli to, co jest wpisane w kodzie. Zmiany, które właściciel robi w panelu admina (cena, „niedostępne dziś”, godziny), widać dopiero w pkt 2.

2. Dane na żywo (moduł JavaScript)

Moduł wr-api.js bierze dane bazowe i nakłada na nie aktualne ustawienia z panelu. Działa w przeglądarce i w Node 18+.

import { getMenu, getHours, isOpenNow, getNotice, getInfo }
  from "https://wloskarobota.eu/api/wr-api.js";

const menu = await getMenu();      // aktualne ceny, dostępność, własne produkty
const open = await isOpenNow();    // { open: true, closesAt: "20:00" }
const hours = await getHours();    // godziny + dni wolne (z świętami)
const note = await getNotice();    // komunikat z góry strony albo null
const info = await getInfo();      // adres, telefon, dowóz
FunkcjaZwraca
getMenu({includeHidden}){ items[], categories[], live }; pozycja ma price, priceText, available, custom
getHours(){ days[] (0 = niedziela), closedDates[], holidayNames, live }
isOpenNow(date?){ open, closesAt | opensAt | reason }; czas liczony w strefie Europe/Warsaw
getNotice(){ text, type } albo null
getInfo()jak info.json, z aktualną listą miejscowości dowozu

Pole live: false oznacza, że ustawień z panelu nie dało się pobrać i zwrócono dane bazowe. Wyniki są trzymane w pamięci przez 60 sekund.
